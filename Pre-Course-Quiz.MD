## **1. Multiple Choice (1 point each)**

1. Which of the following best describes a **large language model (LLM)?**
   a) A database that stores structured data
   b) A machine learning model trained to understand and generate natural language ✅
   c) A frontend framework for web applications
   d) A tool for creating vector embeddings

**Answer:** b (1 point)

2. What is the purpose of **embeddings** in AI applications?
   a) To generate random numbers
   b) To convert text into numerical vectors for semantic similarity ✅
   c) To create HTML forms
   d) To execute Python code

**Answer:** b (1 point)

3. **Retrieval-Augmented Generation (RAG)** is used to:
   a) Retrieve relevant documents and combine them with AI-generated responses ✅
   b) Train models faster
   c) Create chatbots without AI models
   d) Visualize data in charts

**Answer:** a (1 point)

4. Which of these is an example of a **tool** in a LangChain agent?
   a) Calculator function ✅
   b) Vector embedding generator
   c) Flask HTML template
   d) Python virtual environment

**Answer:** a (1 point)

5. Which programming language is primarily used for LangChain and Gemini API integration?
   a) Java
   b) Python ✅
   c) JavaScript
   d) Ruby

**Answer:** b (1 point)
