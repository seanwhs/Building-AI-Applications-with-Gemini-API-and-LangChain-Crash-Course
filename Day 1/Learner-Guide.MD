# 📘 **LEARNER GUIDE**

## *Building AI Applications with Gemini API & LangChain (3-Day Crash Course)*

---

# 🎯 **Course Overview**

Welcome to the **3-day hands-on bootcamp** where you will learn to build real-world AI applications using:

* **Gemini API** (text, embeddings, vision)
* **LangChain** (chains, tools, retrieval, agents)
* **Chroma** (vector database)
* **FastAPI** (backend)
* **Streamlit** (UI)

By the end of this course, you will build and deploy a complete **AI Knowledge Assistant** capable of:

✔ Understanding your documents
✔ Answering complex questions
✔ Using tools (search, calculations, etc.)
✔ Handling images
✔ Running through a web interface
✔ Deployed in the cloud

No prior AI framework experience required — just Python basics.

---

# 🗂️ **Course Schedule**

## **Day 1 — Foundations + Document Pipeline**

You will learn:

* How Gemini + LangChain work together
* How to load documents
* How to chunk, embed, and store them
* How to perform similarity search

**Milestone:**
You will complete the foundational pipeline of a RAG (Retrieval-Augmented Generation) system.

---

## **Day 2 — RAG + Tools + Agents**

You will learn:

* How to build a full RAG assistant
* How to provide citations
* How to add tools and function calling
* How to build AI agents
* Optional: multimodal (Vision) Gemini

**Milestone:**
You will build the full intelligent backend of your AI assistant.

---

## **Day 3 — UI + Deployment + Capstone**

You will learn:

* How to create a front-end interface
* How to serve your AI with FastAPI
* How to deploy your app
* How to present your capstone project

**Milestone:**
You will deploy and demo your final application.

---
